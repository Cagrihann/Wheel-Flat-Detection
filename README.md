# Wheel-Flat-Detection
This project aims to find the best model among various models to detect a wheel flat.

## Models - Accuracy
- Random Forest Classifier -> %95,6
- Gaussian Naive Bayes -> %90,1
- K-Nearest Neighbors -> %95,5
- Multi-layer Perceptron -> %95,8
- XGBoost -> %99,3
- Support vector machines -> %95,4
- Artificial neural network with Tensorflow %94,5
